## About us

Aksali Technologies builds AI systems, software, interfaces, backends, cloud and automation around the problem in front of us. We choose the simplest technology that solves it, and we check that it actually works.

Based in Pakistan, working with clients remotely.

## What we build

| | |
| :-- | :-- |
| **AI and machine learning** | Models and AI features built for a defined task, evaluated against the conditions they will face |
| **Software engineering** | Web applications that are tested, documented and maintainable long after launch |
| **UI/UX design** | Interfaces designed around the people who use them |
| **Backend and data systems** | APIs, databases and data pipelines that hold up under real traffic and real data |
| **Cloud and infrastructure** | Deployment, monitoring and environments that are reproducible and easy to run |
| **Automation and workflows** | Repetitive work turned into reliable workflows, with people kept in charge of the decisions that matter |

## Selected work

- **InsightFlow AI** · An AI business analyst for small businesses that explains what changed in their sales data, with the evidence behind every figure.
- **RoleFit** · A resume optimiser that tailors a resume to a specific role without inventing experience.
- **Locora** · A platform where families and the public report missing and found people, and trained reviewers decide what is published.

## How we work

- **Straight answers.** An honest view of the approach, the risks and the cost of complexity.
- **Evidence, not claims.** We report how a system performs, including its limitations.
- **Yours to keep.** Code, documentation and the knowledge to run it are handed over, so you are never locked in.
