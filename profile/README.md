<br /><br />

<a href="https://aksali.com/work">
  <img src="case-insightflow.png" alt="InsightFlow AI. An AI business analyst that explains what changed in sales data, with the evidence behind every figure. A deterministic engine computes every metric and the model may only phrase what it found. Any answer with a figure the engine did not compute is discarded. 300 backend tests, including an adversarial suite. Built with Next.js, TypeScript, FastAPI, pandas, scikit-learn and PostgreSQL." width="100%" />
</a>

<br /><br />

<a href="https://aksali.com/work">
  <img src="case-rolefit.png" alt="RoleFit. A resume optimiser that tailors a resume to a specific role without inventing experience. Rewrites that add a skill, metric or employer not in the source are rejected, tested by 27 adversarial cases. Deterministic scoring across seven weighted dimensions. Built with Next.js, TypeScript, PostgreSQL, Drizzle ORM, Zod and Playwright." width="100%" />
</a>

<br /><br />

<a href="https://aksali.com/work">
  <img src="case-locora.png" alt="Locora. Missing and found person reports, with trained reviewers deciding what is published. Every report passes a review queue with an append-only audit trail. Public queries never select contact columns and hidden cases answer 404, never 403. Tested as attacks against a real PostgreSQL database. Built with Next.js, TypeScript, PostgreSQL, Drizzle ORM, Zod and Leaflet." width="100%" />
</a>
